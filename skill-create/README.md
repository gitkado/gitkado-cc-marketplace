# skill-create Plugin

Claude Codeスキルの新規作成・改修スキル.

## Overview

プロジェクトの規約に沿った品質の一定したスキルを対話的に作成・改修します。

## Usage

```bash
/skill-create <目的>              # 新規スキル作成
/skill-create migrate <name>     # 既存スキルの規約準拠への改修
```

## Features

- 対話的なユースケース定義・設計
- フォルダ形式のスキルファイル生成
- エージェントファイルの自動生成（必要時）
- 既存スキルの規約準拠チェック・改修
